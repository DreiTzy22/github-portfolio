DOCU-FLOW: A Faculty Extension Document Management System

Project Leader | Lead Programmer | Backend Developer

A production system engineered for the Campus Extension and Training Services (CETS) at Isabela State University Echague Campus to streamline report filing and designate evaluations.

  • 6 User Roles: Tailored portals for Faculty, Coordinator, Dean, CETS Staff, Director, and Evaluators.
  • Audit Trail: In-system notifications, real-time submission tracking, and status monitoring.
  • SMTP Service: Automated email notifications and credentials verification checks.
  • File Handling: Dynamic report consolidation and automated designation certificate generation.
